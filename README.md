📐 Sistema de Cálculo de Trapecios (MVC)

Una aplicación web desarrollada con PHP puro bajo el patrón de arquitectura MVC (Modelo-Vista-Controlador). Este sistema permite a los usuarios autenticados calcular el área y perímetro de un trapecio en tiempo real, además de guardar, editar, eliminar y buscar el historial de cálculos en una base de datos MySQL.

✨ Características Principales

Autenticación Segura: Sistema de Login para proteger el acceso a la aplicación.

Cálculo Dinámico: Interfaz reactiva con JavaScript vanilla que calcula el área y perímetro en tiempo real mientras el usuario digita las medidas.

CRUD Completo: Gestión total del historial de cálculos (Crear, Leer, Actualizar, Eliminar).

Búsqueda Integrada: Motor de búsqueda para filtrar el historial por detalles o medidas específicas.

Diseño Moderno y Responsivo: Interfaz de usuario (UI) atractiva, basada en variables CSS, que se adapta perfectamente a computadoras, tablets y dispositivos móviles.

Iconografía SVG: Uso de gráficos vectoriales escalables para una calidad de imagen impecable sin pérdida de resolución.

🛠️ Tecnologías y Arquitectura

Backend: PHP (Orientado a Objetos)

Base de Datos: MySQL / MariaDB (Usando PDO para prevenir inyecciones SQL)

Frontend: HTML5, CSS3, JavaScript (DOM Manipulation)

Patrón de Diseño: MVC (Modelo, Vista, Controlador)
